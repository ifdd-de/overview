# 01 — What IFDD stands for

**Integration of Federated Data Domains.** German: *Integration föderierter
Daten-Domänen* — the same four letters.

Each word carries weight:

| Word | Claim |
| --- | --- |
| Integration | Bringing views together is the goal, not collecting files in one place. |
| Federated | Parts stay autonomous and are coupled by contracts: schema, context, interface. |
| Data | The subject is described data, not applications. |
| Domains | Ownership is cut along business lines, and the cut is where responsibility sits. |

## Deliberately not in the name

- **No product.** IFDD names an approach; implementations carry their own names.
- **No technology.** LinkML, JSON-LD and REST are current choices, not commitments.
- **No organisation.** Anyone can run a domain and take part.
